מפתח API

לרכבת ישראל אין API ציבורי רשמי. האתר rail.co.il משתמש בלוח הזמנים שלו במפתח מנוי (subscription key) שנשלח מהדפדפן בכל בקשה. כדי שהלוח יעבוד, הדביקו כאן מפתח כזה — הוא נשמר רק בדפדפן שלכם (localStorage), לא בקוד האתר ולא בשום שרת.

אפשר למצוא מפתח עדכני על ידי פתיחת rail.co.il בדפדפן, פתיחת כלי הפיתוח (F12) ← לשונית Network, וחיפוש בקשה אל rail-api.rail.co.il — הערך בכותרת ocp-apim-subscription-key הוא המפתח.
