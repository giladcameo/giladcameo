# מזג אוויר לדרך

אפליקציית PWA לתכנון מסלול לאופנוע. מזינים מוצא, יעד ושעת יציאה, ומקבלים מסלול על המפה צבוע לפי סיכון מזג האוויר בשעה שבה תגיעו בפועל לכל נקודה, ציר זמן לאורך הדרך והצעות לשעת יציאה טובה יותר.

אין שלב build ואין מפתחות API. הכול קבצים סטטיים (JavaScript ללא תלויות, Leaflet נטען מ-CDN).

## הרצה מקומית

דרוש שרת סטטי כלשהו (מודולי ES ו-service worker לא עובדים מ-`file://`):

```
cd moto-weather
python3 -m http.server 8000
```

ואז לפתוח את `http://localhost:8000/`. אפשר גם `npx serve .`.

- מצב הדגמה ללא רשת חיצונית לנתונים: `http://localhost:8000/?demo=1`
- בדיקות: `node --test` (דורש Node 18 ומעלה)

## פריסה

מעלים את תיקיית הפרויקט כמות שהיא לכל אחסון סטטי עם HTTPS, שהוא תנאי ל-service worker ולמיקום:

- GitHub Pages: דוחפים ל-repo ומפעילים Pages מהענף הראשי. כל הנתיבים יחסיים, כך שזה עובד גם מתת-תיקייה.
- Netlify או Cloudflare Pages: גוררים את התיקייה, ללא פקודת build ועם תיקיית פרסום `.`.

אחרי כל שינוי בקבצים חובה להעלות את `VERSION` בראש `sw.js`. כך נוצרת מטמון חדשה, הישנה נמחקת, והמשתמשים רואים הודעת "גרסה חדשה זמינה" ולוחצים "עדכון".

## מגבלות ידועות

- **OSRM**: השרת הציבורי `router.project-osrm.org` הוא שרת הדגמה עם פרופיל רכב בלבד, לא אופנוע. הוא עשוי לבחור כבישים מהירים, והזמנים אינם זמני אופנוע. אין לו הבטחת זמינות ואסור להשתמש בו לעומס כבד. לשימוש רציני יש להקים שרת OSRM או Valhalla משלכם ולהחליף את הכתובת ב-`js/app.js`.
- **Nominatim**: מדיניות השימוש של OpenStreetMap מגבילה לבקשה אחת בשנייה, אוסרת השלמה אוטומטית בצד הלקוח ודורשת שימוש מתון. לכן החיפוש רץ רק בלחיצה על Enter או בעת בדיקת המסלול, והתוצאות נשמרות בזיכרון. אפליקציה עם תנועה גדולה צריכה שירות geocoding משלה. אריחי המפה של OSM כפופים גם הם למדיניות האריחים ואינם מיועדים לתנועה כבדה.
- **Open-Meteo**: התחזית מחושבת כחציון של שלושה דגמים (`icon_seamless`, `ecmwf_ifs025`, `gfs_seamless`), וכשהם חלוקים בהפרש של 3 מעלות ומעלה מוצג טווח הדגמים. הטמפרטורה היא טמפרטורת אוויר בגובה 2 מ׳. השכבה החינמית מיועדת לשימוש לא מסחרי ויש לה מגבלות קצב. התחזית מכסה עד 7 ימים קדימה בלבד, ורזולוציה שעתית. נקודות קרובות מקבלות את אותה משבצת שעה.
- **שעות**: שעת היציאה נקלטת לפי שעון המכשיר. השעות בציר הזמן מוצגות בשעון המקומי של כל נקודה, ומצוין אזור הזמן מעל הציר. כשהמכשיר ואזור המסלול שונים, שימו לב להפרש.
- **תחושת קור לרוכב**: בכל כרטיס מוצגת גם הטמפרטורה כפי שהיא מורגשת במהירות הרכיבה (wind chill לפי נוסחת Environment Canada, עם מהירות אוויר משולבת של הרכיבה והרוח). בורר מהירות הרכיבה (50 עד 130 קמ״ש, ברירת מחדל 90) מחשב מחדש את הציון בלי לפנות שוב לרשת, ונשמר בדפדפן. תחושה של 3 מעלות ומטה היא זהירות, ומינוס 10 ומטה היא סכנה.
- התחזית אינה תחליף לשיקול דעת. הציון הוא הערכה לפי ספי רוח, גשם, טמפרטורה וראות, ואינו כולל מצב כביש, עבודות או אירועי תנועה.
- שמירה מקומית: האפליקציה זוכרת בדפדפן את השפה, ערכת הנושא, מהירות הרכיבה וכתובות אחרונות. המיקום הנוכחי אינו נשמר.
